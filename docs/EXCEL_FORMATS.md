# TopsCore LMS — Excel Import & Export Workflows

> **Module:** Question Bank & Student Ingestion Workflows  
> **Integrity Rule:** Never silently skip invalid rows during file upload. Always validate, preview, and report line-by-line errors.

---

## 1. Question Upload Workflow

```text
SELECT TEST -> DETECT ANSWER TYPE -> UPLOAD -> VALIDATE -> PREVIEW -> CONFIRM -> INSERT
```

### 1.1 Template Schemas by Answer Type

#### Multiple Choice
- **Columns**: `Question`, `Options` (delimiter separated), `Correct Answer`
- Single selection from pre-defined choices.

#### Drop-down
- **Columns**: `Question`, `Options` (delimiter separated), `Correct Answer`
- Embedded inline dropdown selection.

#### Written (Typed)
- **Columns**: `Question`, `Correct Answer`
- Evaluated against tolerance engine (Damerau-Levenshtein $\le 2$ receives 0.5 pt partial credit).

#### Speech to Text (Spoken)
- **Columns**: `Question`, `Expected Answer`
- Evaluated with phonetic and minor spelling tolerance (1.0 pt full credit for minor STT typos).

## 2. Student Batch Import Workflow

```text
UPLOAD -> VALIDATE -> RELATION CHECK -> DUPLICATE CHECK -> PREVIEW -> CONFIRM -> IMPORT -> SUMMARY
```

### 2.1 Student Roster Columns
- `INSTITUTION` (Lookup name or code)
- `PROGRAM` (Program name within institution)
- `Name` (Full student name)
- `Gender`
- `Age`
- `Status` (Optional, default `active`)

> [!CAUTION]
> **No Student ID Column**: As mandated by Rule 2.2, no business-facing Student ID may appear in Excel templates, preview grids, or database inputs. The internal primary key UUID is auto-generated by Supabase.
